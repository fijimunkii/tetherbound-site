ChatGPT + Tailscale

Connect AI to your tailnet without handing it a shell.

TetherBound is a security-first MCP layer for giving ChatGPT, Codex, and other MCP clients narrow, typed access to private machines reachable over Tailscale.

Explore CommunityRead the security model
Tailscale

Private connectivity + identity

Tailscale supplies the private network path and machine identity. The current Linux implementation reaches approved hosts through Tailscale SSH.

TetherBound

AI-specific control boundary

TetherBound independently decides which hosts, tools, services, and result sizes an AI client may use. There is no generic arbitrary-command tool.

MCP

Typed access for AI clients

The same bounded operations are exposed through MCP so ChatGPT, Codex, and other compatible clients can reason about infrastructure through structured tools.

What works today

The Linux proof of concept works end to end: ChatGPT connects through an outbound Secure MCP Tunnel to TetherBound, which uses a dedicated Tailscale identity and Tailscale SSH to inspect explicitly admitted Linux machines.

The current tool surface is read-only: list hosts, inspect a host, summarize system health, inspect disk usage and processes, check exact allowlisted services, and read bounded service logs.

Why not just give ChatGPT SSH?

SSH solves secure remote transport; it does not define what an AI assistant should be allowed to do after it connects. TetherBound deliberately removes the generic command surface and replaces it with fixed operations, independent local policy, exact allowlists, hard execution/output bounds, and auditable request metadata.

Is this a ChatGPT plugin?

The project began under the descriptive private repository name chatgpt-plugin-tailscale. TetherBound is the product name, and the current integration is MCP-based rather than an unrestricted SSH plugin. The historical repo name is retained privately because it describes the project's origin; public Community distribution will use the TetherBound name.

Cross-platform direction

Linux keeps the zero-install Tailscale SSH path. Windows and macOS are planned around a native TetherBound Agent that initiates an outbound tailnet session and exposes the same normalized bounded tools without requiring reusable Windows passwords, WinRM credentials, or arbitrary PowerShell.
